# Remanga-saver
Этот код позволяет скачивать комиксы с сайта remanga.

Данный код в минимально рабочей версии, любые настройки нужно задавать изменяя параметры в коде. 

Скрипт не может скачивать платные главы, скрипт не поддерживает регистрацию на сайте.

Ну и во славу сэйверам. Во славу возможности обладать комиксом, а не только читать на каком то сайте.
